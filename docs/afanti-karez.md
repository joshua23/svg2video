# 阿凡提大战坎儿井辘轳（15 秒动作喜剧动画）

画面、配乐、音效、对白全部由本仓库的代码生成，没有使用任何外部素材。

成片：`renders/afanti-karez.mp4`（1920×1080，30fps，H.264 + AAC，2.39:1 遮幅）

## 改编说明

- 原提示中的"大水车"改为**新疆坎儿井竖井口上方的巨型木辘轳**：两副 A 形木架跨在土路两侧，
  长轴一直伸到路旁的竖井口，轴上是绞绳鼓，绳子吊着水桶垂进竖井；轴的另一端是带 8 块宽叶板的大绞轮。
  水桶下放带动绞轮缓慢转动，所以叶板始终在转。
- 土路旁有一整条坎儿井竖井的环形土堆，笔直穿过戈壁通向辘轳，远处还有另一条坎儿井；两侧是金黄的胡杨林，
  远景是火焰山红色山脊和天山雪峰。
- 原提示写"无音乐"，但按你的要求加了背景音乐（维吾尔风：手鼓 dap + 热瓦普/都塔尔拨弦，D 调希贾兹音阶），
  音量压在音效之下，对白出现时自动闪避；撞击瞬间音乐戛然而止。

## 代码结构

```
src/remotion/afanti/
  plan.ts        分镜表：毛驴运动（240Hz 预积分）、步态相位、辘轳转角、镜头、对白、驴叫时间
  math3d.ts      小型 3D 摄像机：投影、近平面裁剪、凸包
  camera.ts      13 个机位的摄像机运动
  world.ts       确定性随机生成的戈壁、胡杨、岩石、骆驼刺、坎儿井土堆
  scenery.tsx    天空、远山、地面、道路、各类布告板物件
  windlass.tsx   3D 木辘轳（盒子面片 + 光照 + 地面投影阴影）
  rig/           阿凡提与毛驴的侧面/正面 2D 骨骼
  poses.ts       姿势关键帧（每个毛驴动作对应一个不同的阿凡提特技）
  scene.tsx      每帧合成：深度排序、尘土粒子、视角、特效
  AfantiKarez.tsx  Remotion 合成：遮幅、字幕、字体、音轨
scripts/afanti/
  tts.py         离线中文 TTS（FastSpeech2 + MB-MelGAN）合成原始对白
  audio.mjs      JS 合成全部音效与配乐，TD-PSOLA 变声，混音到 public/afanti/soundtrack.wav
  render.mjs     渲染 mp4
```

`audio.mjs` 直接 import `plan.ts`（Node 22 类型擦除），所以蹄声、铃铛、撞击与画面逐帧同步。

## 重新生成

```bash
npm install
# 对白（需要 Python 3.11 虚拟环境）：
python3 -m venv .venv-tts && . .venv-tts/bin/activate
pip install zhtts --no-deps && pip install "tensorflow-cpu==2.15.1" "numpy<2" pypinyin
npm run afanti:voice      # → build/afanti/voice/*.wav
npm run afanti:audio      # → public/afanti/soundtrack.wav（分轨在 build/afanti/stems/）
npm run afanti:render     # → renders/afanti-karez.mp4
```

也可以 `npx remotion studio src/remotion/Root.tsx` 打开 `AfantiKarez` 合成实时预览。

## 声音清单

- 对白：12 句，标贝女声模型合成后，用 TD-PSOLA 把基频降到约 0.6 倍、再把共振峰整体下移 13%，
  得到约 130–165Hz 的男中音；喊叫句加轻微饱和。
- 音效：不规则四拍蹄声（每只蹄子音色不同）、马鞍皮革嘎吱（粘滑摩擦模型）、铜铃（非谐波分音）、
  衣袍呼啦声、毛驴"咿—啊"叫（吸气/呼气交替 + 共振峰）、风声（随速度和机位变化）、
  木头撞击（模态合成）、辘轳木轴吱呀和绳索摩擦、坎儿井暗渠流水、水桶落井水花、手杖旋转呼呼声和插地"嘣"。
- 配乐：手鼓节奏 + Karplus-Strong 拨弦旋律；8 秒后英雄段加厚，11 秒撞击处静默，随后是得意的点弦和惊慌的急奏。
